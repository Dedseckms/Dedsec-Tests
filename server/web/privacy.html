Локальная диагностика

Приложение читает характеристики оборудования, Windows, процессы и доступные датчики. Отчёты и настройки остаются в LocalAppData/DedsecTests. Список процессов не сохраняется в публичный отчёт. Системные настройки автоматически не меняются. До нажатия проверки обновлений или публикации приложение не обращается к GitHub и серверу результатов.

Что попадает в таблицу

После отдельного согласия на конкретный прогон отправляются: модели CPU и GPU, число логических потоков, объём RAM, архитектура, модели/объёмы/тип дисков, редакция и сборка Windows, значения и длительность тестов, версия приложения и методики. Сервер добавляет случайный ID и время публикации. Локальные рекомендации, имена пользователя и ПК, серийные номера, MAC, файлы, пути и процессы не отправляются.

Публичная конфигурация не привязывается к аккаунту, однако редкое сочетание компонентов и дата могут сделать её узнаваемой. Абсолютная неидентифицируемость не обещается.

IP и журналы

При соединении сервер и сетевые провайдеры технически видят IP. Сервис результатов не записывает исходные IP в базу или журналы доступа. Для ограничения спама в памяти процесса на короткое время хранится HMAC адреса со случайным ключом; после перезапуска он не сохраняется. У сайта нет аналитики, рекламных скриптов, сторонних шрифтов, cookie или аккаунтов. Журналы ОС и сетевой инфраструктуры могут содержать технические сведения соединений и не входят в публичную таблицу.

Согласие, хранение и удаление

Отправка выполняется только после просмотра данных и установки флажка. Результаты хранятся до удаления владельцем или модерации. Локальный отчёт содержит секретный ключ удаления: кнопка в приложении удаляет публичный результат. Не публикуйте JSON локального отчёта, если хотите сохранить контроль удаления. HTML-экспорт ключа не содержит. Потеря ключа не позволяет автоматически доказать владение анонимной записью.

Ежедневные резервные копии хранятся в количестве семи; удалённая запись может оставаться в них до ротации. При восстановлении базы необходимо повторно применить удаления, если восстанавливается более ранняя копия. Копирование публичной таблицы третьими лицами не контролируется автором.

Проверка обновлений

Запускается пользователем. Приложение обращается к GitHub API и скачивает пакеты с GitHub Releases. GitHub видит сетевые сведения согласно своей политике. Пакеты проверяются по SHA-256 и подписи манифеста встроенным открытым ключом. Проверка не отправляет аппаратную конфигурацию.

Нагрузка и ограничения

Нагрузочные тесты могут вызвать нагрев, сбой нестабильного оборудования и потерю несохранённой работы. Температурная остановка зависит от доступных и исправных датчиков. Дисковый тест пишет временный файл 256 MiB. Диагностика не выявляет все неисправности, не является антивирусом и не гарантирует исправность системы. ПО распространяется по MIT без гарантий.
