Честные цифры начинаются
с понятной методики.

Dedsec Tests измеряет отдельные операции. Для обзора всего ПК есть условный общий индекс DT Overall v1; он не предсказывает одинаково офисную работу, рендер и игры. Публичные результаты сообщаются клиентом и не проходят аппаратную аттестацию; их можно подделать. Это таблица наблюдений, не сертифицированный рейтинг.

МетрикаЧто измеряется
CPU single / multiSHA-256 блоков 1 MiB, 5 секунд; каждый хэш сверяется с независимым эталоном; один рабочий поток или число логических процессоров. MiB/s. Учитывает аппаратное SHA-ускорение, .NET и планировщик, не заменяет игровые или рендер-тесты.
GPU computeDirect3D 11, feature level 11.0, compute shader cs_5_0: 65 536 потоков × 256 зависимых итераций с записью результата, 5 секунд после прогрева. Miter/s по аппаратным GPU timestamp queries, с проверкой disjoint; пакеты адаптируются к примерно 50 ms. В метрику не входит ожидание CPU; длительность метрики — сумма времени GPU. Проверяется точное совпадение всех целочисленных выходных данных xorshift32 с эталоном на CPU. Есть накладные расходы синхронизации. Это не FPS, не полноценный 3D/VRAM-тест и не оценка всех GPU в системе.
RAM copy64 MiB копирование одним потоком, 4 секунды, проверка совпадения буферов. Число исходных байтов / время. Влияют кэши CPU и среда .NET.
RAM integrityДо 256 MiB выделенной памяти, четыре адресных шаблона. Отображается число несовпадений. Не тестирует всю RAM; не заменяет загрузочный MemTest86.
Диск read / writeВременный файл 256 MiB на выбранном томе, блоки 1 MiB, FILE_FLAG_NO_BUFFERING и WRITE_THROUGH. В запись входит flush, в чтение — проверка данных. Кэш устройства остаётся возможен. Файловая система и шифрование влияют на результат.
Диск latency128 случайных чтений 4 KiB по фиксированному seed из того же файла. Средняя задержка в ms, меньше — лучше. Это небольшая выборка, не полная характеристика IOPS. Модель именно тестируемого физического диска не выводится автоматически из буквы тома.

Как сравнивать

Используйте одинаковую версию методики и одну метрику. Питание от сети, охлаждение, драйверы, фоновые задачи, энергопрофиль, версия .NET и температура меняют результат. Повторите измерение несколько раз после охлаждения. Одиночный прогон не доказывает дефект. RAM errors и latency сортируются по возрастанию; остальные показатели — по убыванию.

Баллы Dedsec Tests — DT v1

Для CPU single/multi, RAM copy и чтения/записи диска: DT = измеренные MiB/s × 1000 / 1024. Для GPU compute: DT = измеренные Miter/s (то есть 1000 баллов за 1 Giter/s). Это фиксированный пересчёт измеренной скорости, без выдуманного эталонного ПК и без зависимости от места в таблице. Сравнивать баллы можно только в одинаковом тесте и версии методики. Сами баллы разных тестов не складываются; отдельный комплексный индекс использует геометрическое среднее и фиксированные веса. Число ошибок RAM и задержка диска остаются в исходных единицах.

Рядом с баллами показывается измеренная скорость: от 1024 MiB/s — в GiB/s, от 1024 GiB/s — в TiB/s; от 1000 Miter/s — в Giter/s. Исходный JSON и сортировка используют исходные числа без пересчёта и округления до баллов.

Общий рейтинг — DT Overall v1

По умолчанию сайт показывает весь ПК: больше общий балл — выше место. Для CPU берётся геометрическое среднее DT single и multi. GPU — DT compute, RAM — DT copy. Для диска берётся геометрическое среднее DT чтения, DT записи и 1000 / задержка в миллисекундах.

Общий балл = CPU0,40 × GPU0,30 × RAM0,15 × диск0,15. Веса постоянны и выбраны для этого обзорного индекса; они не являются измеренными долями производительности приложений. Ускорение любого компонента повышает балл, улучшение одного теста не меняет исходные результаты остальных. Формула не использует место в таблице, цену или выдуманный эталонный компьютер.

В общем рейтинге участвуют только все восемь успешно завершённых проверок с нулём ошибок RAM. Пропущенный GPU, отсутствующий дисковый тест или ошибка означают отсутствие общего балла; такие прогоны видны ниже полных. Ёмкость RAM, FPS, стабильность и все виды нагрузок этим индексом не оцениваются. Отдельные вкладки позволяют выбрать подходящий тест; для скорости больше — лучше, для задержки и числа ошибок меньше — лучше.

Совместимость

Целевая платформа — Windows 10/11 x64 и x86, отдельные сборки с .NET 10. Работа на конкретной редакции Windows и оборудовании требует проверки. GPU-тесту нужен аппаратный Direct3D 11 feature level 11.0; софтверный адаптер пропускается. В системах с несколькими GPU выбирайте адаптер в приложении. Температуры зависят от LibreHardwareMonitor, прав и поддержки датчика; CPU может требовать PawnIO. Приложение не устанавливает драйвер скрыто.

Чего диагностика не обещает

Состояние Защитника, PnP, автозагрузки, свободного места и ограниченный ATA SMART — только часть возможных проверок. Недоступный провайдер WMI не равен успешной проверке. NVMe/USB SMART, питание, кабели, физические дефекты, стабильность всей RAM и совместимость каждого драйвера нуждаются в отдельных инструментах. 60-секундная нагрузка CPU/GPU помогает наблюдать нагрев, но не сертифицирует стабильность и не публикуется как стандартный benchmark.
